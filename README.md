# Simple Interest Calculator

A small Python program that calculates simple interest and the total amount payable on a loan or deposit.

## Formula

```
Simple Interest (SI) = (P x R x T) / 100
Total Amount (A)     = P + SI
```

| Symbol | Meaning |
|--------|---------|
| P | Principal amount |
| R | Annual rate of interest (in %) |
| T | Time period (in years) |

## Features

- Takes principal, rate and time as input
- Validates that the inputs are positive numbers
- Prints the simple interest and the total amount

## Requirements

- Python 3.8 or later (no external libraries)

## How to Run

```bash
python simple_interest.py
```

## Example

```
Enter principal amount: 10000
Enter annual rate of interest (%): 5
Enter time in years: 3

Simple Interest : 1500.00
Total Amount    : 11500.00
```
