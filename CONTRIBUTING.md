# Contributing to Simple Interest Calculator

Thank you for your interest in contributing! All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

### Reporting Bugs

- Open an issue in this repository.
- Describe the problem, the steps to reproduce it, and what you expected to happen.
- Include the input values you used (principal, rate and time) and the output you got.

### Suggesting Enhancements or Ideas

- Open an issue describing your idea and why it would be useful.
- Examples: support for months or days, compound interest, or a graphical interface.

### Submitting Code Changes

1. Fork this repository.
2. Create a new branch for your change:
   ```bash
   git checkout -b my-feature
   ```
3. Make your changes and test them by running `python simple_interest.py`.
4. Commit your changes with a clear message:
   ```bash
   git commit -m "Describe your change"
   ```
5. Push the branch to your fork and open a pull request.

### Improving Documentation

Fixes to the README, comments, or examples are always appreciated.

## Guidelines

- Keep the code simple and readable.
- Follow the existing code style.
- Be respectful to other contributors and follow the [Code of Conduct](CODE_OF_CONDUCT.md).
